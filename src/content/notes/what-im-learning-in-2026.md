Here's what I'm spending my learning time on this year. Most of it makes me better at my job; one
of them is just for me.

## Swift and SwiftUI

I'm building HomeTV, a video app for Apple TV, in Swift and SwiftUI. After years of React Native,
writing a native app from scratch is humbling. The focus engine on tvOS alone changed how I think
about navigation.

## TypeScript, deeper

I've written TypeScript every day for years, but I still learn something each time I read a good
type definition. This year I'm paying more attention to how types shape an API, not just whether
the code compiles.

## System design

I want to get better at the decisions made before any code is written: where data lives, what
happens when a service is slow, and what's worth building at all.

## Astro

This site is built with Astro, and so is Provisoire. Shipping static HTML by default and adding
JavaScript only where it's needed has changed how I build for the web.

## Guitar

Still on the list, still learning. Slowly.

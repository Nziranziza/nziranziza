## Overview

Operator (now Rye) was building an open protocol for e-commerce, where anyone could take part as a
buyer, seller or developer. The Marketplace was a reference storefront that showed what you could
build on top of it.

## The problem

A protocol is hard to explain without something to click. Operator needed a working shop that
partners and developers could try, and that showed products from many merchants in one place.

## What I did

- Built the storefront frontend in React, from the home page to product listings and search.
- Built the sponsored brand carousel and browse sections such as New Arrivals and Top Sellers.
- Managed shared state with the Context API and fetched data from the Operator API with Axios.
- Styled it with SCSS and Bootstrap to match Operator's design.

## Outcome

The Marketplace shipped in 2022 as Operator's demo storefront. It has since been retired, and
Operator is now Rye. It taught me to build against an API that was still changing underneath me.
